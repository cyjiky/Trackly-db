## Про проєкт

**Trackly** - багатофункціональний сервіс, що поєднує персональний трекер звичок та систему управління завданнями з можливістю командної співпраці

## Модель даних

База даних містить 7 основних сутностей та 2 допоміжні таблиці:

- **`USERS`** — користувачі системи (ім'я, нікнейм, контакти, хеш пароля, часовий пояс)
- **`HABITS`** — звички користувачів із періодом дії та статусом
- **`HABIT_COMPLETIONS`** — історія щоденних відміток виконання звичок із нотатками
- **`TASKS`** — завдання з дедлайнами, пріоритетами, статусами та прив'язкою до проєкту/виконавця
- **`WORKSPACES`** — спільні командні простори
- **`WORKSPACE_MEMBERS`** — членство та ролі користувачів у робочих просторах
- **`CATEGORIES`** — категорії / теги для групування активностей
- **`TASK_CATEGORIES`** та **`HABIT_CATEGORIES`** — зв'язувальні таблиці

> Діаграма доступна у [docs/diagramm.mmd](docs/diagramm.mmd)

## Модель розгалуження Git

Командна робота над проєктом ведеться за структурованою моделлю гілкування:

- **`main`** — стабільна гілка з фінальною, захищеною та перевіреною версією документації і коду
- **`dev`** — основна інтеграційна гілка розробки
- **`docs`** / **`lab-N`** — тематичні гілки для конкретних лабораторних робіт та документації
- **`dev_<author>`** (`dev_vu`, `dev_yr`, `dev_kp`) — персональні робочі гілки авторів, зміни з яких вливаються через Pull Requests

Детальніше про гілкування та візуалізацію Git Graph у [docs/uni-labs/README.md](docs/uni-labs/README.md#модель-розгалуження-git-branching-strategy).
