# Специфікація вимог
## 1. Бачення продукту
Потрібна комплексна система, яка об'єднає планування завдань і трекінг звичок. Головна ідея — формування корисних рутин, ведення особистих та робочих процесів.
## 2. Потреби користувачів
- Кожному користувачу потрібен акаунт. 
- Для звичайних користувачів: трекер звичок та завдань.
- Для командної роботи: створення простору для організації співпраці, що потребує наявності різних ролей (адміністратора та учасника).

## 3. Дані для збереження
- Профілі користувачів (нік, електронна пошта, пароль, часовий пояс).
- Списки завдань та звичок.
- Детальна історія змін.
- Робочі простори та списки учасників.
- Власні категорії для персоналізації.
